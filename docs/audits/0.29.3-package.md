# Розмір Windows-пакета 0.29.3

Порівняно фактичні опубліковані ZIP 0.29.1 і 0.29.2 та очищену 0.29.3. МБ у таблиці — десяткові; зайнятий простір на конкретному диску залежить від файлової системи.

| Версія | Архів | Розпаковані файли |
|---|---:|---:|
| 0.29.1 | 241 813 369 байтів | 601 158 102 байти |
| 0.29.2 | 253 978 202 байти | 632 263 262 байти |
| 0.29.3 | 216 115 701 байт | 486 776 429 байтів |

Приріст 0.29.1 → 0.29.2 майже повністю спричинила необов’язкова Linux musl-бібліотека Canvas: 31 045 272 байти без стиснення, 12 158 495 байтів у ZIP. Це помилка пакування. У 0.29.1 також був непотрібний Windows-збірці Linux GNU-модуль. Сам app.asar зріс на 6589 байтів, його стиснена частина — на 1833 байти.

У 0.29.3 з Windows-пакета виключено чужі платформні модулі Canvas і source map-файли залежностей; ресурси Electron залишено uk, ru, en-US. Мовні дані офлайн-OCR ukr, rus, eng збережено. Прибрано 283 файли на 146 083 169 байтів; додатковий обсяг метаданих пакета дає чисте скорочення на 145 486 833 байти. Основний залишковий обсяг — Electron (лише ЛАД.exe становить 235 533 824 байти), його службові бібліотеки й офлайн-обробка документів.

П'ять тестів перевіряють захист збірки: допустимі x64/arm64 PE-бінарники, відхилення чужих платформ, відсутнього/пошкодженого Windows-бінарника, налагоджувальних карт і зайвих мовних ресурсів. Той самий afterPack-захист виконався на справжній Windows-збірці. Усі 79 робочих вихідних файлів збігаються з app.asar. Архів перевірено за CRC; кожний збережений сторонній файл має ті самі байти, що у 0.29.2. Змінилися лише package/ASAR-метадані, цілісність EXE та інструкція версії. Базу користувача не включено.

Фінальну папку створено electron-builder 26.15.3 для win32/x64; ZIP зібрано зі всього її вмісту стандартним Deflate, рівень 9. Старий переносимий EXE мав інше стиснення та розпаковував програму при кожному запуску. ZIP розпаковується один раз, після чого запускається ЛАД.exe з папки.

Бібліотеки документів залишаються окремими файлами, оскільки reader запускається з app.asar.unpacked в окремому worker. Їхнє перепакування без перевірки імпорту на Windows у цю зміну не включено. Нативний запуск Windows і OCR у готовому EXE в цьому середовищі не перевірялися.
