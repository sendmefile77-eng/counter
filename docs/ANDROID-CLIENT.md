# Майбутній Android-клієнт ЛАД

Це план сумісності; APK і обмін персональними тижневими файлами ще не реалізовані.

## Один репозиторій

Поточний Electron-клієнт Windows залишається основним місцем ведення повної бази. Android-клієнт можна додати окремо в `android/`, а опис формату обміну — у `shared-contracts/`. Для APK потрібна окрема ручна збірка; Windows workflow залишається незалежним. Electron не запускається на Android: мобільний інтерфейс створюється окремо, формат і правила даних узгоджуються між клієнтами.

## Персональний тижневий пакет

Керівник обирає співробітника й тиждень, переглядає склад експорту та зберігає файл, наприклад `ЛАД_Юлія_2026-10-19.ladweek`. Співробітник відкриває його на телефоні та переглядає власний розпорядок, наявність, чергування, завдання й підсумки за день/тиждень. Програма працює після імпорту без сервера й постійного з’єднання. Передача файла залишається ручною.

Експорт формує новий документ із дозволених полів одного співробітника. У ньому фізично відсутні повна база, чужі картки, спільний журнал змін, внутрішні примітки, чужі призначення та браузерні адреси. Спільне завдання має окреме персональне представлення; передача його вільного тексту потребує перегляду керівником. Сирі браузерні журнали за замовчуванням не експортуються; для статистики можна передавати денні підсумки з описом способу їх розрахунку.

Контракт міститиме ідентифікатор формату, версію схеми, ідентифікатор джерела, незмінний UUID співробітника, початок/кінець тижня, час формування, номер редакції та масиви власних дат/подій/підсумків. Імена — відображення, UUID — зіставлення. Внутрішні шляхи до файлів та службові об’єкти не передаються. Для чутливих даних можливе шифрування пакета; перевірка справжності потребує окремої цифрового підпису, простий хеш цього не забезпечує.

## Оновлення та історія

Повторний імпорт того самого пакета не створює дублів. Новіша редакція замінює повний обсяг даних свого тижня, включно з видаленими подіями; давніша редакція потребує явного рішення користувача. Різні тижні накопичуються для статистики за місяць і рік. За одним тижневим пакетом телефон показує лише переданий обсяг; довгострокові підсумки потребують попередніх пакетів або окремого персонального експорту історії.

Перший мобільний варіант доцільно зробити для перегляду. Зворотна передача позначок виконання — окремий формат із перевіркою керівником, а не заміна його повної бази.
